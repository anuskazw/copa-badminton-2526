# Copa Femenina de Clubes 2025/2026

Tablón de partidos programados para la Copa Femenina de Clubes de Bádminton organizada por FESBA.

## Características

- Visualización de partidos por fases (Grupos, Cuartos, Semifinales, Final)
- Información de fecha, hora y pista
- Diseño responsive
- Estructura simple y clara

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```
